## 三、韻律結構

### 斷句美學
- **短句切割**：2-4字為一節奏單位（"睡不著 / 在半夜 / 三點整"）
- **空格分隔**：「對妳的愛 / 一直都在 / 像血液 / 流淌在 / 動脈」
- **重複堆疊**：同一句重複 2-4 次形成情緒加深（「走遠 / 走遠 / 走遠」）
- **中文為主 + 英文點綴**：英文從不超過連續 3 句

### 段落結構模板

**類型A — 「凌晨三點」型（創傷回憶型）：**
```
[時間設定] 現在是凌晨三點 → 想妳失眠
[感官觸發] 回憶環繞在周圍
[否定句] 明明說好不哭了
[心疼句] 擔心妳沒人訴苦 / 老天也不舍告別
[崩潰點] 我不爭氣的哭了 / 天空下起大雨
[迴圈重複] 現在是凌晨三點 → 回憶再現
```

**類型B — 「給妳的愛」型（暗戀/失戀型）：**
```
[主歌1] 深夜意象 + 分開半年 + 資格喪失 × 4句
[副歌] 對妳的愛一直都在 + 血液比喻 + 翻動態 × 4句
[主歌2] 觸景傷情 + 內心下雨 × 4句
[副歌重複] + 變奏 + 自我拷問
[尾聲] 只要妳回來 + 什麼都能夠 + 成熟承諾
```

**類型C — 「你知道你比晚霞好看嗎」型（甜蜜浪漫型）：**
```
[時間跳躍] 六月的妳 → 七月的牽掛 → 九月的融洽
[引用句] 「哪怕夕陽美如畫，但我眼裡只有她」
[英文過渡] Oh Listen Baby / You drive me crazy
[承諾句] 為妳衝、為妳瘋、為妳寫浪漫情節
[生活細節] 開車/地鐵、冬天暖手/夏天加冰
[尾聲] 下輩子我的心臟依舊為妳在發燙
```

## 四、語言特徵

### 中文特徵
- **繁體中文**為主（台灣在地化）
- 名詞性短語多，完整敘事句少
- 第二人稱「妳」貫穿全語料（0 個「你」用於情歌）
- **現代都市感**：melody、story、ig(Instagram)、地鐵、Baby、rap、oh、yeah

### 英文混入規律
| 位置 | 英文 | 作用 |
|------|------|------|
| 副歌前過渡 | `Oh` / `Uh` / `Ah` | 節奏呼吸，準備爆發 |
| 呼喚句 | `Baby` / `Girl` | 親密感建立 |
| 強調句 | `Yeah` / `you drive me crazy` | 情感峰值 |
| 句末點睛 | `U already know` / `that's no reason` | 態度感 |
| 粵語混寫 | `我鍾意妳` | 在地化驚喜 |

### 情緒曲線（通用）

```
設定時間（凌晨/深夜/特定月份）
  ↓
感官切入（畫面/血液/心跳）
  ↓
情緒命名（蔓延/佔據/困住/折磨）
  ↓
回憶對比（美好過去 vs 分開半年）
  ↓
副歌爆發（血液/雨/瓶頸比喻）
  ↓
英文點綴（Oh/Baby/Yeah）
  ↓
場景細節（ig動態/地鐵/翻動態）
  ↓
情緒墜落（曲終人散/掙扎/瓶頸）
  ↓
自我拷問 / 接受（放過我 / 曲終人散）
```

## 五、創作模板

### 步驟化框架

```
1. 設定時間 → 失眠/想念切入（凌晨三點OR深夜OR特定月份）
2. 感官切入 → 視覺+觸覺：畫面/血液/心跳/淚
3. 回憶觸發 → 照片/場景/習慣 → 環繞在周圍
4. 情緒命名 → 蔓延/佔據/困住/折磨
5. 否定+崩塌 → 「明明說好不哭」→ 情感反轉
6. 副歌爆發 → 血液/雨/瓶頸/晚霞比喻
7. 英文插入 → Oh/Baby/Yeah（情感峰值）
8. 場景細節 → ig動態/地鐵/Baby/拥抱充电
9. 情緒墜落 → 曲終人散/掙扎/瓶頸/分岔
10. 收尾 → 放過我/下輩子心臟為妳發燙/什麼都能夠
```

### 核心技巧

| 技巧 | 示例 | 效果 |
|------|------|------|
| **具象身體感受** | 「血液流淌在動脈」 | > 「我想念你」100倍 |
| **自然意象比喻** | 「內心在下雨」 | > 「我很傷心」10倍 |
| **反問推進情緒** | 「怎麼可能把妳忘記」 | > 直說更強烈 |
| **留白** | 「妳的畫面全都暫停了」 | > 不說想念，說畫面暫停 |
| **時空壓縮** | 「明明說好不哭了」→崩塌 | > 先否定再破防，張力更強 |
| **重複堆疊** | 「走遠 / 走遠 / 走遠」 | > 情緒加深 |
| **引用句式** | 「哪怕夕陽美如畫，但我眼裡只有她」 | > 記憶點強 |
