# Lo-fi R&B 歌詞創作技能

本技能用於創作台灣/中文 Lo-fi R&B 風格的歌詞，風格參考 BK (Bill Kang)、PPlin、Juice Boy、8lak、Vigoz 等 StreetVoice 生態圈的藝術家。

## 風格特徵

### 1. 主題與情緒
| 主題 | 範例關鍵詞 |
|------|-----------|
| 深夜失眠 | 凌晨三點、深夜、三點半、半夜 |
| 暗戀單戀 | 妳不知道、想要妳的愛、等妳 |
| 錯過遺憾 | 第一次見妳的我、沒有妳、如果當時 |
| 溫柔浪漫 | 好看、晚霞、比晚霞好看、妳的樣子 |
| 都市孤寂 | 一個人、寂寞、沒人懂、孤單 |
| 親情懷念 | 爸、寫給祢的信、天上 |

### 2. 語言風格
- **口語化**：「說了再見」、「不習慣說再見」、「不管過了多久」
- **第二人稱「妳」**（非「你」）— 親密感
- **疊字/語氣詞**：「嘛」、「喔」、「啊」
- **短句為主**：每句 8-12 個字，節奏感強
- **Mix 中文與少量英文**：偶爾摻入 "truthfully"、"baby" 等

### 3. 押韻模式
- **句尾押韻**：中文押韻（an/ang, i/ai, u/ou）
  - 例：「愛」/「在」/「壞」（an韻）
  - 例：「說」/「錯」/「過」（uo韻）
- **ABAB 或 AABB 結構**：常見於副歌
- **句內押頭音**：罕見，以句尾韻為主

### 4. 歌曲結構
```
[Intro/Hook]       — 1-2 句，旋律性強，先聲奪人
[Verse 1]           — 4-8 句，描述情境/場景
[Pre-Chorus]        — 2-4 句，情緒升級
[Chorus]            — 4-8 句，高潮，情感最強烈
[Verse 2]           — 4-8 句，敘事/故事推進
[Chorus]            — 重複或微調
[Bridge]            — 2-4 句，轉折/新視角（可選）
[Outro/Chorus]      — 結尾，留白或 fade
```

### 5. 典型 Verse 模式
```
場景設定 → 情緒投射 → 具體細節 → 情感爆發
Example:
我在凌晨三點的房間（場景）
想著妳的臉（情緒投射）
電話沒接 訊息已讀不回（具體細節）
我該怎麼做（情感爆發）
```

### 6. 典型 Hook/Chorus 模式
```
[叠句+情感濃縮]
「沒有妳我怎麼可能開心」
「妳對我多重要」
「你知道你比晚霞好看嗎」

特點：
- 主語 + 感受/判斷，結構簡單
- 用問句引發共鳴：「妳知道嗎？」
- 用否定句強調：「沒有妳...」
```

## 創作流程

### Step 1: 確定核心情感
從以下選一個（或多個組合）：
- 🌙 深夜孤獨感
- 💔 暗戀/失戀
- 🌅 浪漫/溫暖
- ⏳ 錯過/遺憾

### Step 2: 設定場景關鍵詞
```
時間：凌晨三點、半夜、深夜、傍晚
地點：房間、街頭、咖啡廳、捷運
感官：電話、酒、手機訊息、路燈
```

### Step 3: 句尾韻腳規劃
先想好韻腳，再開始寫：
- `ang/eng`: 等、疼、曾、朋、楓
- `an`: 愛、難、慢、看、散
- `i/ai`: 說、錯、過、ai、愛
- `u/ou`: 孤、呼、路、哭

### Step 4: 第一句定調
Lo-fi R&B 的第一句通常是**視角+場景**，不解釋：
```
✅ 「凌晨三點我坐在床邊」
✅ 「房間只剩手機的光」
❌ 「那天晚上我失眠了」（太直接）
```

### Step 5: 疊加情緒
- Verse: 描述觀察 (objective)
- Pre-Chorus: 情緒開始浮現 (transitional)
- Chorus: 內心獨白爆發 (subjective)

## Prompt 模板（用於 AI 輔助創作）

```
幫我寫一首 Lo-fi R&B 風格的中文歌詞。

主題：{描述核心情感，如「暗戀卻不敢說出口」}
場景：{描述時間地點，如「凌晨三點、獨自在房間」}
韻腳：{指定韻腳，如「ang」}
長度：{如「Verse 8句 + Chorus 8句」}
風格：{如「BK 的溫暖失戀感」或「8lak 的慵懶 rap-singing」}

要求：
- 口語化，不要太文縐縐
- 用「妳」而非「你」
- 短句為主，每句 8-12 字
- 句尾押韻
- 避免陳腔濫調（「我愛你」、「傷心欲絕」）
```

## 禁忌（避免清單）
- ❌ 不要用「心碎」、「心碎成一百片」
- ❌ 不要用「永遠愛你」、「海枯石爛」
- ❌ 不要過度文學化（「星光斑駁」）
- ❌ 不要寫超過 15 字的句子（Lo-fi 的精髓是留白）
- ❌ 不要用「我愛你」（太直接，用「我需要妳」或「我只想見妳」）

## 驗證方法
完成後自我檢查：
1. 朗讀時是否有節奏感？（數字數）
2. 是否每 2-4 句押韻？
3. 情緒是否從節制到爆發的張力？
4. 是否有具體的感官細節（聲音、畫面）？
5. 是否避開了上面的禁忌詞？
