## 一、主题意象库

### 核心意象
| 意象类型 | 具体词 |
|---------|-------|
| **时间点** | 凌晨三點、半夜、深夜 |
| **身体/感受** | 內心、血液、動脈、心臟、臉紅、觸景傷情、垂頭喪氣 |
| **思念状态** | 蔓延、佔據、藏在心底、想念、折磨 |
| **情绪词** | 沈默、空虛、孤獨、悲傷、感動 |
| **自然意象** | 晚霞、夕陽、星空、夜雨、天空 |
| **日常意象** | 動態(社媒)、melody、story、地鐵、Baby |
| **回忆/遗憾** | 回憶、資格、現實、夢境、分開、失去 |

### 高频句式
- 「睡不著，在半夜，三點整」
- 「對妳的愛，一直都在」
- 「沒有妳，就不算成功」
- 「內心在下雨，思念像折磨」
- 「哪怕夕陽美如畫，但我眼裡只有她」

## 二、韵律结构

### 断句风格
- 短句切割（2-4字为一节奏单位）
- 大量使用空格作为节奏分隔符
- 押韵但不强制，英文混写增加音域

### 段落结构（以「給妳的愛」为例）
```
[主歌1] 深夜意象 × 4句 → 情感爆发句 × 2句 → 回忆句 × 2句
[副歌]  对核心主题(爱/思念)的浓缩表达 × 4句
[主歌2] 场景描写(動態/story) × 4句 → 情绪坠落 × 4句
[副歌]  重复+变奏
[尾声]  主题回归
```

## 三、语言特征

### 中文特征
- **繁體中文**为主（台灣在地化）
- 大量名词性短语，非完整叙事句
- 第二人称「妳」贯穿（女性视角的情歌）
- 现代都市感词汇（melody、story、Baby、rap）

### 英文混入规律
- 句末强调：`U already know` / `that's no reason` / `drive me crazy`
- 插入副歌过渡：`Uh` / `Yeah` / `Baby`
- 英文常与中文形成感叹或情感爆发点

### 情绪曲线
```
深夜 → 思念蔓延 → 回忆美好 → 现实失落 → 自我拷问
→ 「沒有妳，就不算成功」→ 反复自责 → 情绪坠落 → 接受现实
```

## 四、创作模板

### 结构化写作框架
```
1. 时间设定（通常深夜/凌晨）
2. 感官切入（视觉+触觉：画面/血液/心跳）
3. 情绪命名（蔓延/占据/折磨）
4. 回忆对比（美好 vs 现实现实：分开/半年/资格）
5. 副歌爆发（对核心主题的比喻化表达）
6. 场景细节（现代生活场景：翻动态/坐地铁/拥抱充电）
7. 英文插入（情感高潮点）
8. 收尾（自我承诺/遗憾回归）
```

### 关键技巧
- 用**具象身体感受**代替抽象情绪：「血液流淌在动脉」> 「我很想念你」
- 用**自然意象**类比情感：「内心在下雨」> 「我很伤心」
- 用**反问/自问**推进情绪：「怎麼可能會把妳忘記」> 直接说想念
- **留白**：不说「我想你」，说「妳的畫面全都暫停了」
